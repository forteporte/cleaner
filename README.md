# Чистка телефона — Android (версия для мамы)

Проверяет телефон на мусор и чистит его:

- **WhatsApp:** просмотренные статусы, стикеры, гифки.
- **Мусор:** миниатюры галереи, установочные APK, логи и временные файлы, пустые папки.
- **WhatsApp и Telegram:** кнопки, которые открывают экран очистки кеша.

## Как собрать (Windows)

1. Поставь [Android Studio](https://developer.android.com/studio).
2. Распакуй архив, в Android Studio: **File → Open** → выбери папку `PhoneCleaner`.
3. Подожди, пока внизу закончится синхронизация Gradle (первый раз 5–10 минут, качает зависимости).
   Если Studio предложит обновить Gradle или плагин — соглашайся.
4. Собрать APK: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
   Файл появится в `app/build/outputs/apk/debug/app-debug.apk`.
5. Кинь APK на телефон (Telegram «Избранное» подойдёт), открой его и разреши установку из неизвестных источников.

Можно и сразу на телефон: включи на нём «Режим разработчика» → «Отладка по USB», подключи кабелем и нажми зелёный ▶ Run в Studio.

## Что увидит мама

Один экран, огромные кнопки с надписями «МАМА, НАЖМИ СЮДА…»:

1. При первом запуске — кнопка, чтобы дать разрешение на доступ к файлам (один раз).
2. «Проверить телефон на мусор» → «Удалить мусор» → «Готово, освободила N МБ».
3. Кнопки для WhatsApp и Telegram: открывают системный экран, где нужно нажать «Хранилище» → «Очистить кеш».

Удаляется только безопасное: просмотренные статусы, стикеры и гифки WhatsApp, миниатюры галереи, установочные APK, логи, пустые папки. Фото, видео, документы и переписки приложение не трогает.

## Ограничения Android

С Android 11 ни одно приложение без root не может само удалить кеш другого приложения из `Android/data`. Поэтому кеш Telegram чистится кнопкой, которая открывает нужный экран.
